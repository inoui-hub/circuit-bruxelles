# Itinéraires à Bruxelles — atelier de classe

Exercice sur les critères d'organisation : chaque élève formule une demande en mots-clés, un camarade construit l'itinéraire qui y répond, puis le demandeur l'évalue.

- `index.html` — page élève : connexion (classe cochée dans la liste du professeur), demande en mots-clés, demandes de la classe, construction de l'itinéraire (6 points max.), feuille de route reçue et évaluation (3 critères).
- `prof.html` — tableau de bord enseignant : classes ouvertes, élèves en ligne, demandes, superposition des itinéraires (une couleur par élève), synthèse des évaluations.
- `live.html` — écran de projection en direct (carte plein écran, points qui apparaissent au fil de l'eau). Se lance depuis le tableau de bord.
- `collecte-google.gs` — serveur (Google Apps Script + Google Sheet). Mode d'emploi en tête de fichier.
